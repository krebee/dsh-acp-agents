## セキュリティ強化 / Security hardening

- 承認サービス不在時の fail-closed 化、デスクトップ承認のループバック接続・HTTP 応答の検証
- ACP エージェント間でのホスト環境由来の認証情報の分離、マスキングと診断ログの改善
- Git worktree の作成先・削除対象の検証、未登録ディレクトリの再帰削除の禁止
- 日本語 README と 3 言語のドキュメント、CI とチェックサム付き配布

### 互換性に関する注意 / Compatibility

API keys, tokens, proxy settings and other nonstandard environment variables previously inherited from the host must be configured explicitly on the intended Agent. This is defense in depth, not a guarantee against malicious agents; credentials remain locally stored, and host/OS sandbox and network policies still matter.

### インストール

```sh
dsh plugin --profile web add ./dsh-acp-agents-0.4.10.tgz
```

使用するプロファイルに合わせて `web` を変更してください。配布ファイルは `SHA256SUMS` と照合できます。通常の単体・回帰テストと、実際のホスト連携テストは別です。後者はホスト環境での確認が必要です。
